# РыбТочки

Бесплатная карта рыболовных точек и сравнение прогнозов ECMWF, GFS и ICON для iPhone.

Сайт: https://vlad9463.github.io/map_weather/

Публикация: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Прогнозы: Open-Meteo. Картографические подложки: Esri World Topographic Map и Esri World Imagery. Точки сохраняются локально в браузере, доступны импорт и экспорт.

## Семидневный прогноз и измерения воды

Сводка погоды на 7 дней и полные часы каждого выбранного дня берутся из Open-Meteo. Недельная таблица разворачивается для общей оценки условий.

Раздел «Волга · уровень и температура воды» содержит ссылки на [СНТ Бугорок](https://www.snt-bugorok.ru/level/uroven-v-saratovskom-vodokhranilishche-u-samary-segodnya) и [ФГБУ «Приволжское УГМС»](https://pop.pogoda-sv.ru/hydrometeocenter/region_hydrology/) и позволяет вручную хранить текущие измерения с датой. Пока нет подтверждённого публичного API, автоматический сбор гидропоказателей не выполняется.

### Автоматические данные Волги
GitHub Actions проверяет уровень на гидропосту Самары через СНТ «Бугорок» и региональную расчётную температуру воды через «Русоир» трижды в сутки (если источники разрешают доступ); JSON сохраняется в `data/volga-samara.json`. Уровень может быть в **м БС**, а резервный относительный показатель в **см над нулём поста** — они не взаимозаменяемы. Температура относится к **Самарской области**, не к точному гидропосту Волги; использовать как справочный региональный прогноз. Источники и даты показываются в интерфейсе. Ручные замеры независимы от автоматической сводки.

Сервис-воркер со старым офлайн-кешированием больше не устанавливается и удаляется при открытии обновлённого сайта.
